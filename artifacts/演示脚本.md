# 演示脚本（3 至 5 分钟）

本脚本用于初赛视频录制与决赛现场演示。全程围绕一个业务问题展开：市场下跌时，应当在触达客户之前先预演一遍。演示使用合成脱敏数据，全程不涉及任何真实客户信息。开始录制前请先执行 `npm run dev` 并确认首页左上角显示"系统运行正常"。

## 一、录制准备

- 启动开发服务器：`npm run dev`，访问 http://localhost:3000
- 浏览器窗口设为 1600 × 1000，隐藏书签栏与开发者工具
- 若配置了模型密钥，界面会显示"模型模式 · LLM 在线"；未配置时显示"规则模式 · 未配置模型"，讲解词按实际显示切换
- 提前把任务输入框清空，避免上一次的文本干扰画面

## 二、分镜脚本

### 第 1 段｜提出问题（0:00 至 0:35）

画面：停留在智能任务中心首页，鼠标停在左侧导航与顶部任务输入框。

讲解词：

"券商在暴跌行情下面临一个时间差问题。客户情绪在当天上升最快，服务动作必须在几个小时内铺开，但事后复盘挽回不了已经发生的投诉和流失。我们做的这件事，是把策略评估的节点从触达之后前移到触达之前：先让一群虚拟客户把这条策略跑一遍，再决定发不发、发给谁、用什么话术。"

### 第 2 段｜一句自然语言驱动全流程（0:35 至 2:00）

操作：在任务输入框输入下面这句话，点击"开始分析"。

```
市场今天下跌 30%，请分析持有高波动产品的客户，生成三套沟通方案，模拟未来 48 小时的客户群体反应，并告诉我应该优先联系谁。
```

讲解词（进度实时展开时）：

"我输入的是一句自然语言，没有填任何表单。界面上正在展开的是 Agent 自己生成的执行计划：先抽取场景参数，再按客群口径筛选客户，构建画像和关系网络，起草三套策略，执行群体模拟，最后过一遍合规硬边界。每一步都有真实耗时和真实输出，这套轨迹不展示模型的原始思维链，只展示工具调用和结构化证据。"

指向执行概览后继续：

"这几个数字说明了这次任务的结果。跌幅和时长来自我这句话里，客户规模、时间步和种子使用了默认值，界面会明确提示哪些参数是默认值，不会静默忽略。恐慌峰值、投诉风险和流失风险由确定性数值引擎算出，同一场景同一随机种子必然复现。"

### 第 3 段｜客户洞察与一人一策（2:00 至 2:45）

操作：点击左侧"客户洞察中心"，指向高风险客户队列，再点击队列中的第一位客户。

讲解词：

"这里按模拟期的峰值暴露给客户排序。之所以用峰值而不是期末状态，是因为干预生效之后大家的期末情绪都会回落，按期末排会给出一份人人低风险的名单，没有业务价值。点开任意一位客户，可以看到他的六维性格雷达、个体行为随时间步的变化，以及一人一策的沟通建议，包括触达时机、渠道、话术要点和话术红线。"

### 第 4 段｜策略对比与合规硬边界（2:45 至 3:45）

操作：点击"群体行为沙盘"，展示三套策略的结果对比与传播网络；再点击"策略与审计"。

讲解词：

"沙盘里比较了三套锚点策略。这里的推荐顺序不是写死的：引擎按「避险收益 − 触达成本 − 唤醒成本」的净效用在每个场景里算出来，所以微跌时它建议先不打扰，重挫且持续时间长时才转向分群深度干预。当前这个 30% 跌幅的 48 小时场景，推荐的是统一风险提示。右边还能看到参数空间搜索的结果——那是理论最优的参数组合，但它还没生成草稿、也没过合规审查，所以系统推荐的是已经审过的锚点方案。这张网络图里，五类客户原型分群布局，节点颜色和大小随个体状态变化，三类关系边参与传播计算。"

切到策略与审计后继续：

"这是合规部分。合规不是模型的一环，而是模型之外的硬边界。规则引擎一共 19 条规则，覆盖收益承诺、诱导性紧迫表达、适当性越级推荐、风险揭示缺失等类别。注意这一条：'我不会催促您立即操作，也无法承诺收益'这句话字面上命中了两个规则，但语义上是免责说明，规则引擎识别否定语境后把它降级为提示，没有误拦。而这一条真正越级的推荐被直接拦截并强制改写，规则编号、命中片段、字符区间和处理状态都记录在审计里。"

### 第 5 段｜能力边界与收尾（3:45 至 4:30）

操作：点击"Skill 与审批"，指向候选技能与已批准记录。

讲解词：

"最后说清楚边界。模型负责理解目标、规划步骤、抽取参数、起草策略和解释结果；群体数值模拟和合规判定由确定性代码执行，模型绕不过合规这一层。任务成功后 Reflector 会生成候选技能，但无审批的在线学习是关闭的，候选技能必须人工批准后才可复用，也不会自动修改引擎参数。当前所有客户数据都是合成的，我们没有接入真实生产数据，因此不宣称任何真实客户行为的预测准确率。"

## 三、现场演示的操作要点

- 断网或模型不可用时不切换方案，直接展示规则模式，界面徽标会显示"规则模式"或"降级模式"，讲解时如实说明即可
- 首次进度反馈在 400 毫秒内出现，若网络较慢，等待进度条推进时保持讲解词连贯
- 任务失败时界面会给出错误码、重试与取消按钮，这是可讲的功能点，不必回避
- 演示结束前刷新页面，任务与审计记录会重新加载，可用来证明结果已持久化

## 四、常见提问的应答口径

- **这和普通的 LLM 客服工具有什么区别**：普通做法把判断全部交给模型，结果不可复现也不可审计。我们把模型限制在语言任务上，群体数值模拟与合规判定由确定性代码执行，因此同一个场景和种子必然复现，合规边界也无法被绕过。
- **虚拟客户的行为准不准**：目前没有真实数据，我们不宣称预测准确率。当前验证的是系统行为的一致性与方向性，例如跌幅从 10% 升到 30% 时恐慌、卖出和流失不会反向下降。数据到位后需要重新校准心理参数。
- **为什么不做第二个场景**：初赛选择单场景是为了把一条纵向闭环做完整，产品推荐适当性预演安排在决赛阶段。
- **合规规则会不会误伤正常话术**：规则引擎带否定语境识别，32 条标注语料的误拦截率为 0，唯一一条漏检属于待复核类别，已进入迭代清单。
