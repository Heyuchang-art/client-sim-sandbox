## 结论摘要

1. **最刺眼的问题不在「术语太多」，而在侧边栏直接暴露了技术架构**：`Harness 状态 / Planner / Tool Registry / Policy Gateway`（第 169-173 行）是给工程师看的，一线用户完全无从理解，且占据常驻位置。

# 二、信息架构与减负方案

## 2.1 智能任务中心（`:310-400`）

当前首屏一次性呈现：输入框、执行模式徽章、默认值提示、执行进度、失败告警、三个参数徽章、四个指标卡、执行计划（8 步列表）、客户群体传播预览（含网络图 + 4 条进度条 + 热点提示）。

**首屏必须**：输入框 + 开始按钮、执行进度、四个指标卡（高风险客户 / 恐慌峰值 / 投诉风险 / 合规发现）。
**默认收起**：「执行步骤」（8 行列表，默认折叠为「执行步骤（8 步）· 展开查看」）；「客户情绪扩散预览」整卡下沉到群体沙盘页，或折叠为一张缩略图 + 「查看沙盘」按钮。
**次级位置**：执行模式徽章（`llm/rule/degraded/local`）移到页面右上角小字，不进主视线。
**可合并**：`:365-368` 四个指标卡的 hint 文案压缩，去掉「按模拟峰值暴露排序」「模拟期末值」这类口径说明，统一放进标题 tooltip。
**「有了更好但不影响决策」**：引擎毫秒数、端到端秒数、首帧毫秒数（`:363`）——这三个数字对评委有用，对一线无用，建议收进「本次任务的完整记录」。

首次进入时该页应该看到：**一个输入框、一句话引导、四个关键数字**。

## 2.2 客户洞察中心（`:402-451`）

当前：左栏客户队列表（多列）+ 右侧四张卡（客户详情含雷达图、个体动态行为六个指标、一人一策含话术/要点/红线/证据徽章、客户记忆摘要）。

**首屏必须**：客户队列（只留「客户 / 优先级 / 恐慌 / 卖出」四列）+ 「一人一策」卡（这是客户经理真正要用的）。
**默认折叠**：六维性格雷达、个体动态行为六指标（`客户洞察`的雷达图对业务方是「好看但不当饭吃」，建议折叠进「更多画像」）。
**次级位置**：客户记忆摘要（移到「一人一策」下方，默认折叠）。
**可合并**：「沟通要点」与「话术红线」两张列表可以合并成一张「可以这样说 / 不要这样说」双栏对照，比现在分开两块更易用。
**去掉**：「数据已脱敏」（`:424`）——这是免责声明，应移到页脚全局声明，不必每页重复。

## 2.3 群体行为沙盘（`:453-499`）

当前：三张策略选择卡、群体传播回放（网络图 + 播放）、当前群体状态（4 指标）、宏观沟通指挥方案（三阶段 + 右侧五行要素）、策略恐慌曲线对比、结构化因素解释。

**首屏必须**：三张策略选择卡 + 当前群体状态四个指标 + 情绪走势图。
**默认折叠**：「宏观沟通指挥方案」的右侧要素栏（目标客群/触达渠道/沟通节奏/责任主体/升级规则）——这是执行细节，折叠为「查看执行细节」。**但「合规边界」那一行（`:491`）必须留在明面**。
**次级位置**：「结构化因素解释」整卡移到「策略与审计」页，它属于解释性内容，不属于沙盘操作流。
**可合并**：「群体传播回放」与「当前群体状态」本来就是同一件事的两面，建议合并成一张卡：左边图、右边四个数字。

## 2.4 策略与审计（`:508-615`）

**这是信息过载最严重的一页**：同屏依次是策略结果对比（九列表）、参数空间搜索（七列表）、合规发现、执行审计轨迹、任务与模型信息（十余个事实卡）、人工反馈、责任声明。

**建议改为「三段式 + 两层」**：
- 第一段（明面）：**推荐结论**一句话 + 策略结果对比（主表五列）+ 合规发现（只显示待处置项）。
- 第二段（默认折叠）：参数空间搜索、执行审计轨迹、任务与模型信息、人工反馈。
- 第三段（常驻底部）：责任声明（`:615`）与免责声明。

**表格拆分建议（明确回答）**：
- 策略比较九列表 → **主表五列**（方案 / 综合推荐度 / 风险改善 / 人力成本 / 打扰代价）+ 每行末尾「明细」展开，展开后显示恐慌峰值、卖出倾向、流失风险、合规风险。九列并排会横向溢出，且用户一次只能比较 2-3 个维度。
- 参数空间搜索七列表 → **整卡默认折叠**，表内只留「组合 / 覆盖客户 / 人工方式 / 效果评分」四列，技术参数放进该行的展开区。理由：这张表回答的是「系统还试了别的吗」，属于探索性问题，不是决策必经路径。
- **审计轨迹与任务与模型信息 → 默认收起，保留入口**，位置建议放在页面底部同一个「查看完整记录」折叠区内。这两块的目标读者是评委与合规，不是客户经理。收起不违反任何要求：内容仍在、仍可导出、仍随报告附出。
- **人工反馈**：保持可见但缩小为一行（满意度按钮 + 「补充意见」链接），展开后才显示文本框。

## 2.5 Skill 与审批（`:647-730`）

当前：说明条 + 关闭无审批学习提示 + 技能卡片流（每卡含状态、指标网格、来源任务 ID、三个操作按钮）。

**默认折叠**：指标网格（十余个键值对，见 A8）。
**次级位置**：「来源任务」ID（`:722`）——一串 UUID 对用户无意义，改为「查看来源任务」链接。
**可合并**：候选与已批准建议分成两个分区或加筛选，现在混在一起靠状态徽章区分，扫读成本高。
**必须保留**：「无审批在线学习已关闭」（`:715`）——这是安全声明，且是赛题「反思进化层」的关键说明，不能删。
